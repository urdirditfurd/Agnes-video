# Agnes / Atelier Vidéo

Deux modes disponibles :

| Mode | Fichier | Description |
|---|---|---|
| **Classique** | [`Agnes.html`](./Agnes.html) | Images fixes → clips animés via Agnes AI |
| **Pro** | [`atelier-video-pro/`](./atelier-video-pro/) | Script texte → scènes → images → clips → montage (jusqu’à 20 min) |

## Démarrage rapide (Pro)

```bash
cd atelier-video-pro
npx --yes serve -p 4173
```

Ouvrez `http://localhost:4173`, ajoutez votre clé Agnes, chargez la démo « Le voyage d'une goutte d'eau ».

Documentation complète : [`atelier-video-pro/README.md`](./atelier-video-pro/README.md).
