v1.3 · pack complet + HTTP · 3 heures
⛔ Fichier HTML ouvert incorrectement Vous avez ouvert un index.html seul via file:// (ex. Téléchargements). FFmpeg.wasm est introuvable → aucune vidéo 3H ne peut être assemblée.

Correct : utilisez le dossier complet ambiance-video-v1/ (avec lib/ffmpeg/) puis :
  1. Windows : double-cliquez demarrer.bat
  2. Mac/Linux : ./demarrer.sh
  3. Ou : python -m http.server 8765 dans ce dossier
  4. Ouvrez http://127.0.0.1:8765/ (pas le fichier local)
Mode local par défaut FFmpeg.wasm · sans VPS
Important : ne téléchargez pas seulement le HTML. Servez le dossier complet via demarrer.bat / demarrer.sh → http://127.0.0.1:8765/
Aucune clé Agnes — requise pour créer la vidéo
