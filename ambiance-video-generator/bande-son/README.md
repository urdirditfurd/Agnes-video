# bande-son/

Dépose ici **les 2 fichiers** du projet (image + audio), puis lance `../demarrer.bat` ou `../demarrer.sh`.

## Noms acceptés

L’app charge automatiquement le **premier** fichier image et le **premier** fichier audio trouvés dans ce dossier.

Exemples :
- `capybara-automne.png` + `lofi-onsen.mp3`
- `image.jpg` + `audio.mp3`
- `ambiance.webp` + `bande-son.wav`

Formats image : `.jpg` `.jpeg` `.png` `.webp`  
Formats audio : `.mp3` `.wav` `.ogg` `.m4a`

## Workflow

1. Copie image + bande-son dans ce dossier
2. Lance le serveur local (`demarrer.bat` / `demarrer.sh`)
3. Ouvre http://127.0.0.1:8765/
4. Vérifie le prompt automne cozy (éditable)
5. Colle ta clé Agnes → **Veille flux jusqu’à succès**
